**无需重新打包 APK、无需服务器**——导入后存在手机 localStorage，永久有效。

## 生效方式：不用手动导入，服务器一键下发

本文件夹里的 `qpack-*.json` **不需要**再手动传到手机拖拽导入。
`tools/db.py` 的数据层已经会自动扫描这里所有 `qpack-*.json`，
与内置 `db/*.json` 合并成同一份「在线题库」一起对外提供：

- `GET /api/version` 的版本指纹会把这些采集题库也纳入计算，内容变化即版本号变化，App 端会自动感知「有新版本」
- `GET /api/bank` 返回的完整题库里已经包含了这里的四级/六级/考研词库（合并后约 4200+ 题）

所以真正的使用路径简化为一步：

1. 双击启动 `启动服务器.bat`（会自动起 serve.py + ngrok 隧道 + 把当前公网地址回写进单文件版）
2. 手机打开考途 App（内置地址与隧道域名一致时零配置；域名变了在「我的 → 一键下载在线题库」的地址栏填一次）
3. 点「立即从服务器下载」→ 拿到内置题库 + 这里的采集词库全量内容

下载后：
- 词卡分类出现在对应赛道 Tab 下（如「四级核心词·词卡」在 CET-4 赛道）
- 词卡分类自动走**词卡极简模式**（默认展开答案、大单词标题）
- 学习进度只存手机本机，不会因为重新下载被覆盖

## 重新采集 / 扩充

```bash
python tools/fetch_datasets.py                 # 默认：四级/六级/考研乱序全本
python tools/fetch_datasets.py --limit 500     # 每本最多 500 词（小体积试水）
python tools/fetch_datasets.py --books CET4_1  # 只抓关键字匹配的词书
```

跑完后无需额外操作，serve.py 按文件 mtime 自动重载，下次「一键下载」即包含最新词库。
